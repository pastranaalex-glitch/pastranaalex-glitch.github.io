# Vídeos de la Biblioteca

Guarda aquí los vídeos de demostración de las aplicaciones en MP4 (H.264/AAC).

- `lector-facil.mp4`: demostración de Lector Fácil. Al publicar este archivo, aparecerá automáticamente el botón «▶ Ver vídeo» junto a «↓ Descargar gratis» en `lector-facil.html`.

Para subirlo desde GitHub: abre esta carpeta, selecciona **Add file > Upload files**, elige el archivo `lector-facil.mp4` y pulsa **Commit changes**.
