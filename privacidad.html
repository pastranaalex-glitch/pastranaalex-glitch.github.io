Privacidad y opiniones

Información sobre opiniones, privacidad y avisos por correo de la Biblioteca de herramientas.

Visitar y descargar

Esta web está alojada en GitHub Pages. Los archivos APK se distribuyen mediante GitHub Releases. La Biblioteca no incorpora anuncios, tienda ni herramientas propias de seguimiento de visitantes.

GitHub puede tratar datos técnicos para prestar y proteger sus servicios; consulta su información de privacidad.

Valoraciones de una a cinco estrellas

En el catálogo puedes puntuar cada aplicación sin indicar tu nombre ni correo. Al votar se crea un identificador aleatorio y se guarda en el almacenamiento local del navegador para mantener un único voto activo por aplicación y navegador. Puedes cambiar tu puntuación: el sistema sustituye el voto anterior.

El identificador se transforma en un hash mediante una clave secreta antes de guardarlo en la base de datos de Cloudflare D1. Se conserva la aplicación valorada, la puntuación y la fecha de actualización. Para frenar abusos se contabilizan temporalmente intentos por conexión utilizando hashes de duración limitada (sin guardar la dirección IP en texto claro). Cloudflare Turnstile verifica los envíos y puede procesar datos técnicos necesarios para identificar tráfico automatizado. No se comprueba si la aplicación está realmente instalada.

Las valoraciones de 1 y 2 estrellas cuentan exactamente igual que las demás y pueden ir acompañadas, de forma voluntaria, de un comentario en Google Forms. En la web solo se publica la media y el número de votos, no identificadores ni datos individuales. Puedes consultar la política de privacidad de Cloudflare. Para consultar o solicitar la retirada de una valoración, puedes utilizar el formulario de contacto.

Enviar una valoración

El formulario externo de Google Forms solicita una puntuación, tipo de mensaje, comentario y versión de la aplicación. El nombre o apodo es opcional y puedes elegir si autorizas que tu comentario se publique.

Al utilizar el formulario, las respuestas se envían a Google, sujeto a sus condiciones y políticas de privacidad. No incluyas teléfonos, direcciones, contraseñas, correos ni información personal de otras personas.

Moderación antes de publicar

Las respuestas originales no se publican automáticamente. Solo pueden aparecer en la web las opiniones que autorices y que sean aprobadas después de revisarlas. Se muestran las estrellas, apodo indicado (o «Anónimo»), tipo de mensaje y el texto aprobado. No se publican las respuestas marcadas como privadas.

Las opiniones pueden incluir críticas. La revisión tiene como finalidad eliminar spam, ataques personales o datos privados, no ocultar valoraciones negativas.

Solicitar retirada de una opinión

Si has publicado una opinión y deseas retirarla, puedes utilizar el mismo formulario para solicitarlo, indicando el apodo y el texto que enviaste. La petición se revisará para identificar la entrada correspondiente. Evita incluir más datos personales de los necesarios.

Avisos voluntarios por correo

La Biblioteca ofrece un formulario voluntario para recibir avisos de nuevas aplicaciones y actualizaciones. El formulario se gestiona mediante Brevo. Se solicitará únicamente una dirección de correo electrónico y el consentimiento específico para recibir novedades. El consentimiento no es un requisito para descargar programas.

La suscripción utilizará una confirmación doble: tras enviar el formulario, deberás confirmar desde el enlace recibido por correo antes de empezar a recibir avisos. Cada mensaje incluirá un enlace para darse de baja.

La base jurídica para tratar el correo es tu consentimiento, que puedes retirar en cualquier momento. El correo se utilizará exclusivamente para informar de nuevas aplicaciones y actualizaciones de la Biblioteca; no para publicidad de terceros ni para vender datos. Puedes solicitar acceso, rectificación, supresión, limitación u oposición al tratamiento, así como presentar una reclamación ante la AEPD si consideras que tus derechos no han sido atendidos. La gestión de suscripciones se realizará conforme a las políticas del proveedor. Puedes consultar la política de privacidad de Brevo.

Responsable y contacto: el responsable es la persona titular del proyecto Biblioteca de herramientas. Para consultas sobre tus datos, puedes responder al correo remitente de los avisos, siempre que se haya configurado una dirección de respuesta válida. Puedes retirar tu consentimiento mediante el enlace de baja de los mensajes. Los contactos permanecerán inscritos hasta que soliciten su baja o dejen de ser necesarios para los avisos; se conservará la información imprescindible para acreditar el consentimiento y respetar las bajas conforme a la normativa aplicable.

Jardín de Joyas: estadísticas voluntarias de progreso

En la aplicación Android Jardín de Joyas puedes elegir si deseas compartir el nivel máximo que has completado. Si aceptas, el juego envía únicamente el número del nivel a un servicio de Google Apps Script, que registra el récord global en una hoja de Google Sheets para decidir cuándo añadir niveles. No solicita nombre, correo ni registro, y el sistema no identifica a los jugadores individualmente.

La participación es voluntaria y puede desactivarse en los ajustes del juego. Si no hay conexión, la partida sigue funcionando sin Internet. Google puede procesar información técnica necesaria para prestar y proteger el servicio. Consulta su política de privacidad.

Jardín de Joyas: comprobación de nuevas versiones

Las versiones que incorporan esta función pueden consultar al iniciar el juego el catálogo público HTTPS de la Biblioteca para comprobar si existe una actualización. Esta comprobación no envía tu nombre, los niveles superados ni identificadores de jugador. Como sucede con una visita normal a una web, el servicio de alojamiento puede tratar datos técnicos de conexión, incluida la dirección IP.

La comprobación automática se puede desactivar en Ajustes → Accesos → Buscar al iniciar. También se puede solicitar manualmente desde esos ajustes. El juego no descarga ni instala actualizaciones sin intervención del usuario: abre el enlace oficial para que cada persona decida si descarga e instala la APK.

Mente Activa PRO: datos locales y actualizaciones

Mente Activa PRO es una colección de juegos de entretenimiento. Sin cuentas, publicidad, analítica, compras ni suscripciones. El historial, los favoritos y las puntuaciones se guardan en el móvil y no se envían a la Biblioteca ni a terceros.

Se conservan los ajustes, incluida la preferencia de mostrar la portada, una memoria limitada de retos recientes para espaciar repeticiones, la lectura del aviso y hasta 300 partidas con juego, dificultad, puntuación, aciertos, fecha y modalidad. Las partidas de la selección diaria añaden su día correspondiente. Los resúmenes utilizan únicamente las partidas guardadas. Las preferencias de búsqueda de actualizaciones y las fechas de comprobación también se guardan en el dispositivo.

Los juegos funcionan sin conexión. La app consulta por HTTPS el catálogo público de la Biblioteca alojado en GitHub Pages para comprobar si existe una versión nueva. La búsqueda automática está activada inicialmente, se realiza al abrir como máximo una vez al día y puede desactivarse en Ajustes → Actualizaciones. También puedes buscar manualmente. La consulta no incluye partidas, puntuaciones ni identificadores personales. El alojamiento recibe los datos técnicos normales de la conexión, como la dirección IP.

Al elegir Actualizar se abre el enlace oficial de GitHub en el navegador, que gestiona la descarga. Android pide confirmar la instalación. No se instala nada en silencio. La app no solicita ubicación, cámara, micrófono, contactos ni acceso al almacenamiento.

Desde Ajustes → Borrar todos mis datos puedes eliminar el historial, los favoritos y las preferencias locales. Desinstalar o borrar el almacenamiento desde Android también elimina los datos. La copia de seguridad de Android está desactivada. Consultar la ficha de Mente Activa PRO →

Información sobre los contadores

El contador público de descargas consulta los datos de GitHub Releases. Las cifras representan descargas de archivos APK y no necesariamente personas distintas ni instalaciones en móviles.
