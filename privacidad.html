Privacidad y opiniones

Información sobre opiniones, privacidad y avisos por correo de la Biblioteca de herramientas.

Visitar y descargar

Esta web está alojada en GitHub Pages. Los archivos APK se distribuyen mediante GitHub Releases. La Biblioteca no incorpora anuncios, tienda ni herramientas propias de seguimiento de visitantes.

GitHub puede tratar datos técnicos para prestar y proteger sus servicios; consulta su información de privacidad.

Enviar una valoración

El formulario externo de Google Forms solicita una puntuación, tipo de mensaje, comentario y versión de la aplicación. El nombre o apodo es opcional y puedes elegir si autorizas que tu comentario se publique.

Al utilizar el formulario, las respuestas se envían a Google, sujeto a sus condiciones y políticas de privacidad. No incluyas teléfonos, direcciones, contraseñas, correos ni información personal de otras personas.

Moderación antes de publicar

Las respuestas originales no se publican automáticamente. Solo pueden aparecer en la web las opiniones que autorices y que sean aprobadas después de revisarlas. Se muestran las estrellas, apodo indicado (o «Anónimo»), tipo de mensaje y el texto aprobado. No se publican las respuestas marcadas como privadas.

Las opiniones pueden incluir críticas. La revisión tiene como finalidad eliminar spam, ataques personales o datos privados, no ocultar valoraciones negativas.

Solicitar retirada de una opinión

Si has publicado una opinión y deseas retirarla, puedes utilizar el mismo formulario para solicitarlo, indicando el apodo y el texto que enviaste. La petición se revisará para identificar la entrada correspondiente. Evita incluir más datos personales de los necesarios.

Avisos voluntarios por correo

La Biblioteca ofrece un formulario voluntario para recibir avisos de nuevas aplicaciones y actualizaciones. El formulario se gestiona mediante Brevo. Se solicitará únicamente una dirección de correo electrónico y el consentimiento específico para recibir novedades. El consentimiento no es un requisito para descargar programas.

La suscripción utilizará una confirmación doble: tras enviar el formulario, deberás confirmar desde el enlace recibido por correo antes de empezar a recibir avisos. Cada mensaje incluirá un enlace para darse de baja.

La base jurídica para tratar el correo es tu consentimiento, que puedes retirar en cualquier momento. El correo se utilizará exclusivamente para informar de nuevas aplicaciones y actualizaciones de la Biblioteca; no para publicidad de terceros ni para vender datos. Puedes solicitar acceso, rectificación, supresión, limitación u oposición al tratamiento, así como presentar una reclamación ante la AEPD si consideras que tus derechos no han sido atendidos. La gestión de suscripciones se realizará conforme a las políticas del proveedor. Puedes consultar la política de privacidad de Brevo.

Responsable y contacto: el responsable es la persona titular del proyecto Biblioteca de herramientas. Para consultas sobre tus datos, puedes responder al correo remitente de los avisos, siempre que se haya configurado una dirección de respuesta válida. Puedes retirar tu consentimiento mediante el enlace de baja de los mensajes. Los contactos permanecerán inscritos hasta que soliciten su baja o dejen de ser necesarios para los avisos; se conservará la información imprescindible para acreditar el consentimiento y respetar las bajas conforme a la normativa aplicable.

Información sobre los contadores

El contador público de descargas consulta los datos de GitHub Releases. Las cifras representan descargas de archivos publicados para instalar las aplicaciones (como APK y EXE) y no necesariamente personas distintas ni instalaciones completadas.
