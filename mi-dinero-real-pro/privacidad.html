Política de privacidad

Última actualización: 12 de noviembre de 2026

PrivacidadCondiciones de uso

Resumen: Mi Dinero Real PRO es un programa gratuito de uso personal para Windows. Los movimientos y análisis se guardan en el propio ordenador. La conexión bancaria, si el titular decide activarla, utiliza la API de Enable Banking y la autorización del banco.

1. Finalidad y alcance

El programa facilita a su titular la consulta, clasificación y análisis de movimientos de sus propias cuentas bancarias. Este documento describe el funcionamiento previsto de la versión Windows 2.1. No se ofrece una plataforma pública de cuentas ni un servicio para clientes.

2. Datos utilizados y almacenamiento

Los extractos CSV/Excel importados y los movimientos, importes, fechas, descripciones, categorías y reglas se procesan localmente. Los datos persistentes del programa se almacenan en la carpeta %LOCALAPPDATA%\MiDineroRealPRO del ordenador. El almacenamiento local de la aplicación se protege mediante las funciones de cifrado de Windows (DPAPI) vinculadas a la cuenta del usuario.

Las exportaciones, informes, archivos CSV/JSON y copias de seguridad que el usuario guarde fuera del programa no están cifrados por la aplicación. Se recomienda conservarlos en lugares privados y protegidos.

3. Conexión opcional con BBVA

Si se configura la conexión, el programa consulta la información bancaria autorizada mediante Enable Banking, proveedor externo de conectividad bancaria, y los sistemas de la entidad financiera. La aplicación no solicita ni guarda las contraseñas de acceso a BBVA. Sí conserva localmente, de forma cifrada, la clave de la aplicación API y la información de sesión necesaria para la conexión.

Al autorizar la conexión, BBVA y Enable Banking tratarán los datos necesarios conforme a sus propios avisos y condiciones. El titular puede revisar los términos de Enable Banking y la información que se le muestre durante el consentimiento bancario.

4. Transmisión de información y terceros

La aplicación no envía extractos a un servidor propio del desarrollador. Cuando se utiliza la conexión bancaria, comunica las solicitudes y recibe la información desde los sistemas de Enable Banking. No incorpora publicidad, analítica de uso ni rastreadores propios.

5. Conservación y control

Los movimientos permanecen en el equipo hasta que el usuario los elimina o elimina los archivos del programa. La desconexión desde la aplicación borra su configuración de conexión local, sin necesariamente revocar un permiso que deba revocarse también en BBVA o Enable Banking. Las copias exportadas deben eliminarse por separado.

6. Esta página web

Esta página es un documento informativo estático: no contiene formularios ni recopila datos bancarios. Está alojada en GitHub Pages; GitHub puede tratar datos técnicos de acceso, como direcciones IP, conforme a sus propias políticas.

7. Cambios

Este texto podrá actualizarse si cambia el comportamiento del programa, el proveedor bancario o las funciones ofrecidas. No se publicarán movimientos personales, claves ni datos de acceso en esta página.
