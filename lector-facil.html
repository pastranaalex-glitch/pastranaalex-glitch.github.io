Qué puedes hacer con Lector Fácil

Funciones orientadas a leer documentos y preparar intervenciones sin depender de una conexión a Internet.

▤

Leer PDF y Word

Consulta archivos PDF y documentos Word modernos (.docx) desde tu móvil o tableta.

▣

Identificar interlocutores

Diferencia las partes de cada persona con resaltados para seguir un diálogo.

▶

Teleprompter

Prepara exposiciones y sigue el texto durante una presentación.

♧

Marcadores de lectura

Recupera la posición de lectura y ajusta la presentación del documento.

⇧

Compartir con un compañero

Prepara y exporta documentos en PDF y Word para compartirlos con otras personas.

▧

PDF para imprimir

Crea documentos A4 en blanco y negro, con distribución compacta para ahorrar papel y tinta.

Cómo descargar e instalar Lector Fácil

El archivo es un APK de Android distribuido gratuitamente desde la página de versiones del proyecto.

  1. Descarga el APK

    Pulsa «Descargar APK gratuito» desde un dispositivo Android.

  2. Abre el archivo

    Encuéntralo en Descargas y toca el archivo .apk que hayas descargado. El nombre puede variar según la versión.

  3. Autoriza la instalación si Android lo solicita

    Permite temporalmente instalar desde esa aplicación de origen. Comprueba el nombre del archivo y vuelve a desactivar el permiso después.

  4. Abre Lector Fácil

    Ya podrás utilizar la aplicación sin necesidad de conexión a Internet.

Por seguridad, descarga el APK únicamente desde el enlace oficial de esta página o desde el repositorio del proyecto. La instalación y los avisos pueden variar según el dispositivo.

Preguntas frecuentes

¿Lector Fácil es completamente gratuito?

Sí. No hay pagos, suscripciones, publicidad ni donaciones.

¿Qué Android necesito?

Android 8.0 o superior, según la configuración técnica de la versión 1.0.

¿Puede abrir cualquier PDF?

Permite abrir PDF, pero el texto de los PDF escaneados o basados solo en imágenes puede no estar disponible para ciertas funciones. No debe asumirse que reconoce texto de fotografías automáticamente.

¿Qué documentos Word admite?

El formato Word moderno .docx. No se anuncia compatibilidad con todos los archivos antiguos .doc.

¿Cómo sabré si hay una nueva versión?

Puedes consultar el historial de versiones en GitHub. El APK no se actualiza automáticamente desde Google Play.

¿Necesito instalar la aplicación para leer el PDF compartido?

No. Los PDF exportados pueden abrirse con cualquier visor PDF compatible.
