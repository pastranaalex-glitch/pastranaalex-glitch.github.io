Abre y edita documentos con herramientas habituales de formato, tablas e imágenes.

Usa el borrador de recuperación y el historial de versiones para proteger tu trabajo.

Es una versión beta. Guarda copias de tus documentos importantes y comunica cualquier problema antes de usarla como herramienta principal.

Actualizaciones dentro de la aplicación

Texto Fácil puede avisar cuando exista una versión más reciente. Para activar la comprobación, abre Archivo → Opciones → Ayuda → Actualizaciones y pega esta dirección:

https://pastranaalex-glitch.github.io/texto-facil-version.json

La aplicación consulta el número de versión y abre la página de descarga solo si eliges hacerlo; no instala cambios automáticamente.

Cómo instalar la beta

  1. Descarga el ZIP y extrae su contenido en una carpeta.
  2. Ejecuta TextoFacil.exe desde la carpeta extraída.
  3. Para comprobar futuras versiones, configura el enlace HTTPS indicado arriba.
