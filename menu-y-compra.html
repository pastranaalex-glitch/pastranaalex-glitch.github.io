Cómo instalar Menú y Compra

  1. Pulsa «Descargar APK» cuando aparezca el enlace disponible.
  2. Abre el archivo APK en tu móvil Android.
  3. Si Android te pregunta, permite la instalación desde el navegador o gestor de archivos que has utilizado.
  4. Abre la aplicación y empieza por el menú semanal o tu lista de compra.
Antes de cambiar de versión: exporta una copia de seguridad desde la aplicación. Las versiones firmadas con claves distintas no se instalan una encima de otra. Conserva tus datos antes de desinstalar.

Privacidad y funcionamiento

No necesitas crear una cuenta. La aplicación funciona sin conexión para las tareas de planificación, recetas y compras. Puedes exportar manualmente tus datos para conservarlos. No incluye publicidad ni suscripciones.
